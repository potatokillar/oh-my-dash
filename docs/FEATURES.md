# DSH 手机客户端 — 功能设计

> 版本：v2.0.0+9 · 本文档只描述已实现的功能，不含规划项。
>
> v2.0.0 起客户端由 Flutter 重写为 React + Capacitor（`dsh-mobile/`），功能口径不变；Flutter 旧版已从仓库移除（git 历史可查）。

## 1. 设备管理

- **多设备列表**：设备 = 一台运行 dsh web 的主机（名称 + 地址），本地持久化保存
- **在线状态探测**：进入列表时对每个设备执行握手（`host.describe`），在线设备显示当前模型与工作目录，离线显示原因
- **设备操作**：添加（地址格式校验）、编辑、删除（二次确认）
- **记忆最后设备**：下次启动直达该设备的会话界面
- **独立连接**：每个设备独立的 RPC 客户端与事件流；切换设备自动断开旧连接并重连
- 旧版单地址配置自动迁移为默认设备

## 2. 项目（按目录分组）

- **项目即目录**：会话按其工作目录（cwd）自动聚合为项目，无需手工归属
- **项目卡片**：目录名（已注册 workspace 则用其标题）、完整路径、会话数
- **空项目**：通过"添加项目"注册的目录（暂无会话）同样展示
- **项目内会话**：点进项目只看该目录下的会话；在项目内新建会话自动落在本目录
- **未知目录**：工作目录缺失的会话单独归组
- **添加项目**：通过目录浏览器选择主机上的目录并注册（幂等，重复添加有提示）

## 3. 目录浏览器

- 浏览主机文件系统（`host.listDirectory`）：面包屑 chip 链（当前目录高亮、可点击跳转）、子目录导航
- 隐藏目录开关（点开头目录默认隐藏）
- 新建文件夹（`host.createDirectory`）
- 条目过多时的截断提示
- 底部主操作：「在此目录创建会话」/「添加此目录为项目」（按进入场景切换）

## 4. 会话

- **双视图同源**：项目视图（按目录分组）与会话视图（全量列表）是同一数据的两个角度，每个会话两侧均可到达
- **会话列表**：按最近活跃倒序，按「今天 / 昨天 / 更早」分组；显示标题、目录、模型预设、更新时间、运行中状态
- **新建会话**：从项目内（落在本目录）或目录浏览器（所选目录）创建
- **重命名**：聊天页菜单内修改，多端实时同步
- **会话信息**：sessionId、工作目录、当前模型（provider/model/推理强度）
- 已归档会话自动从所有列表隐藏

## 5. 聊天

- **历史加载**：进入会话加载最近消息，滚动到顶部自动向上分页，位置不跳动
- **消息渲染**：用户/助手气泡、思考过程（reasoning）折叠块、图片占位卡、日期分隔条
- **实时流式**：WebSocket 事件流驱动，流式增量与最终消息渲染；断线指数退避自动重连
- **发送**：多行文本 + 图片附件（多张、自动压缩、可逐个移除）
- **停止**：turn 进行中发送键变为停止按钮，可中断当前生成
- **等待指示**：「正在思考」三点打字动画
- **快捷操作**：空会话引导页（光晕球 + 2×2 bento 卡片）与会话内 composer 上方横滑 chip（写代码/解释概念/头脑风暴/总结文字），点击填入提示词前缀，不直接发送
- **多端同步**：手机与其他客户端（如 PC 浏览器）打开同一会话时，双方消息与状态实时一致

## 6. 模型切换

- **composer 内模型 chip**：显示当前模型，点击弹出选择弹层
- **弹层**：按 provider 分组（DeepSeek、Kimi 等），模型卡片 + 推理强度档（如 Off/High/Max）
- **每会话独立**：选择作用于当前会话
- **不可用警告**：当前模型路由不可用时输入区上方显示警告条
- provider 加载失败计数提示

## 7. 远程审批

- 智能体请求工具权限时弹出审批对话框：工具名 + 说明，「允许一次」/「拒绝」
- 应答协议：原样回显请求 rpcId（`POST /api/respond`）
- 重放去重：重连后重复的待审批帧不重复弹窗

## 8. 界面设计系统

- **主题**：近黑背景 + 蓝紫 accent，surface 分层，卡片 20 圆角 + 微亮描边
- **字体**：Manrope（拉丁文/数字），中文系统字体回退；排版层级（大标题 28 紧字距 / 问候 32 / 正文 15 / 说明 12）
- **氛围**：全局环境光斑、composer 浮起辉光、渐变问候语、空状态引导
- **动效**：消息入场（淡入上移）、光晕球呼吸、页面切换 fade+slide、点按缩放、骨架屏加载
- **空状态**：大图标 + 引导文案（设备/项目/会话/聊天/目录）

## 9. 工程质量

- 协议层纯函数解析（报文→模型，见 `dsh-mobile/src/lib/dsh/protocol.ts`）；UI 与数据层分离，页面只走 `trpc.*` hooks
- `npm run check`（tsc）零问题；`npm run lint` 存量 14 个错误集中在 shadcn/ui 模板组件与 trpc.tsx 导出形状，不阻断出包
- 版本管理：`package.json` 语义化版本 + `android/app/build.gradle` 单调 versionCode，每次出包递增（流程见根目录 AGENTS.md）

## 配套（非 App 本体）

- **dsh-remote-access 插件**：dsh profile bundle，为远程客户端挂载应用内目录浏览后端、声明式追加信任主机；安装 `dsh plugin --profile web add`
- **部署**：dsh web 绑回环，经 `tailscale serve` TCP 转发到 tailnet（`http://100.103.29.13:3080`），APK 分发通道 `:8080`
- **协议验证脚本**（`dsh-remote-access/scripts/`）：全链路 RPC 验证（probe.mjs）、双端同步验证（sync-test.mjs）
